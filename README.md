# Just to do it

Приложение для проектов и задач: Grid/List/Kanban, Markdown, поиск, закрепление, Telegram-аккаунты, синхронизация устройств и офлайн-работа. Интерфейс рассчитан от 360 px, канбан на десктопе располагается в две колонки.

## Локальная проверка существующих задач

Нужен Node.js 24 LTS (`.nvmrc`).

```sh
npm ci
npm run dev
```

Откройте прежний адрес `http://localhost:4000`. Данные этого режима остаются в `todo_app` в localStorage. До первой записи новой версии сделайте [резервную копию](docs/vps-static.md#1-проверка-на-своих-данных-до-публикации).

## Сервер и Telegram

```sh
cp .env.example .env
# Укажите токен @just_to_do_it_bot в .env; файл не входит в Git.
npm run build
npm run server
```

Серверный адрес по умолчанию — `http://localhost:4001`. Вход требует подтверждения в Telegram. Каждый пользователь получает отдельную базу проектов внутри своего аккаунта; данные других аккаунтов недоступны. Домен можно добавить позже через `APP_ORIGIN`.

В разделе «Telegram и аккаунт» доступны импорт старых локальных задач, резервная копия и расписание отправки задач на сегодня. Импорт выполняется явно и сохраняет оригинал localStorage. Сообщения боту добавляют задачи в Inbox.

После первого онлайн-запуска production-интерфейс открывается офлайн. Изменения сохраняются в IndexedDB и отправляются после восстановления связи. Пересекающиеся правки показывают конфликт вместо молчаливой перезаписи.

## Импорт проекта из файла

В разделе «Импорт проектов и задач» скачайте шаблон JSON, заполните проект и задачи, загрузите файл и подтвердите предпросмотр. Эта же форма принимает старые резервные копии Todo. Существующие данные сохраняются. [Формат и примеры](docs/import.md).

## Проверки

```sh
npm run format:check
npm test
npx playwright install chromium
npm run test:e2e
npm run build
```

Тесты используют временные базы, отдельные браузерные профили и имитацию Telegram. Реальные данные и настоящий бот в них не участвуют. `npm run preview` показывает статическую сборку на 4002 без API и аккаунтов.

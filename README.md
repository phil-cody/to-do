# To-do — планировщик задач
## Демо

https://phil-cody.github.io/to-do/


Небольшое одностраничное приложение на JavaScript для ведения проектов и задач. Данные сохраняются в `localStorage`.

## Возможности

- создание, редактирование и удаление проектов и задач;
- назначение задачам срока и приоритета;
- просмотр задач по выбранному проекту и фильтрация по сроку;
- сохранение данных между перезапусками браузера.

## Стек

JavaScript (ES modules), HTML, SCSS, Webpack, date-fns.

## Запуск

```bash
npm install
npm run watch
```

Команда `npm run watch` поднимает локальный сервер разработки. Сборки для development и production доступны через `npm run dev` и `npm run prod`.

Проект создан в рамках обучения The Odin Project и дорабатывался как самостоятельная практика работы с состоянием приложения, модулями и браузерным хранилищем.

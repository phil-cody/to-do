# Решения и ограничения

| Решение                                | Причина и последствие                                                                              |
| -------------------------------------- | -------------------------------------------------------------------------------------------------- |
| Node.js 24 и встроенный SQLite         | Один процесс на VPS, без отдельного сервиса БД и серверных npm-зависимостей                        |
| Вход подтверждением в Telegram-боте    | Общая основа для аккаунта, Inbox и расписания; виджет на странице не нужен                         |
| Telegram ID как владелец               | Изменение username не меняет аккаунт; ID берётся из доверенных Bot API updates                     |
| Открытая регистрация                   | Любой Telegram-пользователь получает собственную область, без доступа к чужим данным               |
| Полный серверный снимок с ревизией     | Совместимость модели и атомарная запись; If-Match защищает от устаревших изменений                 |
| Очередь правок и объединение по полям  | Независимые правки объединяются, пересечение требует решения пользователя                          |
| IndexedDB отдельно по аккаунтам        | Офлайн-очередь переживает закрытие вкладки; API-ответы не кешируются service worker                |
| SSE и резервный опрос                  | Быстрые обновления с восстановлением после обрыва соединения                                       |
| Long polling бота                      | Публичный webhook не требуется; допускается один poller для токена                                 |
| Постоянная очередь исходящих сообщений | Отправка повторяется после сетевой ошибки; при неопределённом результате возможен повтор сообщения |
| Явный импорт localStorage              | Старые задачи не загружаются в аккаунт автоматически; оригинал сохраняется                         |
| Overdue вычисляется из даты            | Нет отдельного сохраняемого статуса, противоречащего сроку                                         |
| Закрепление независимо от порядка      | FIFO-группа закреплённых, остальные по числовому приоритету                                        |

## Текущие ограничения

Поддерживается один backend-процесс с одной SQLite-базой и одним Telegram poller. Совместное редактирование одного поля не является редактором реального времени: конфликт разрешается явно. История изменений, делегирование задач, общие проекты нескольких пользователей, админ-панель и самостоятельное удаление аккаунта пока отсутствуют.

Вход на новом устройстве требует сети и Telegram. Офлайн допускается ранее подтверждённый аккаунт до 7 дней с последней онлайн-проверки; секреты и данные браузерного профиля не шифруются приложением. После отзыва сессии офлайн-устройство узнает об этом при восстановлении сети. Несинхронизированные правки сохраняются до повторного входа в тот же аккаунт.

Кеш интерфейса обновляется после закрытия старых вкладок. Уход из аккаунта блокируется при непустой очереди, чтобы не удалить несинхронизированную работу. Расписание бота включается пользователем отдельно от входа и продолжает работать после выхода из браузера.

Реальные домен, токен и сеть VPS проверяются после настройки. Автотесты используют имитацию Telegram и не подтверждают доставку настоящему боту.

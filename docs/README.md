При изменении поведения обновляйте соответствующий документ и проверку. Секреты, реальные задачи, SSH-параметры и резервные копии в эту базу не добавляйте.

## Порядок использования

- Разработчик: разработка → архитектура → данные → сервер и безопасность.
- Пользователь импорта: шаблоны → заполнение → предпросмотр → подтверждение.
- Публикация: проверки → коммит/push → release:prepare → release:upload → release:install. Все команды релиза выполняются на Mac; первая установка VPS описана отдельно.

Правила формата и лимиты сведены в data.md, заполнение файлов — в import.md, сетевой контракт — в server.md. Не копируйте параметры из старого временного архива: версия релиза определяется SHA, а не именем файла. Локальные проверки инфраструктуру VPS не заменяют.

[Аудит сложности от 19 октября 2026 года](ponytail-audit.md): выполненные упрощения, область и результаты проверок.

# База знаний Todo

Документация описывает текущую React-версию. Начните с [разработки](development.md), если запускаете проект, или с [VPS](vps.md), если публикуете его.

| Документ                                 | Что в нём                                                                  |
| ---------------------------------------- | -------------------------------------------------------------------------- |
| [Устройство приложения](architecture.md) | Структура исходников, компоненты, сохранение, диалоги и сборка             |
| [Данные](data.md)                        | Формат localStorage, миграция старых задач, сортировка и закрепление       |
| [Поведение интерфейса](behavior.md)      | Согласованные правила отображения и адаптивности                           |
| [Разработка и проверка](development.md)  | Команды, тесты, диагностика, куда вносить изменения                        |
| [Решения и ограничения](decisions.md)    | Архитектурные решения и границы текущей реализации                         |
| [Деплой на VPS](vps.md)                  | Git push, SSH, бесплатный поддомен, доставка, HTTPS, запуск, копии и откат |
| [Сервер и API](server.md)                | Аккаунты, API, версии, синхронизация и офлайн                              |
| [Безопасность](security.md)              | Проверенные меры защиты и границы проверки                                 |

[Telegram-бот](telegram.md): вход, Inbox, команды, расписание и доставка.

При изменении поведения обновляйте соответствующий документ и проверку. Секреты, реальные задачи, SSH-параметры и резервные копии в эту базу не добавляйте.

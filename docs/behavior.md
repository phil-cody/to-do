# Поведение интерфейса

## Проекты и задачи

- Под заголовком sidebar расположены All tasks & projects и Project dashboard, затем проекты двумя вертикальными подсписками: Pinned projects и Other projects.
- Новое закрепление добавляет проект в конец первой группы. Числовой порядок влияет на незакреплённые проекты.
- Общая рабочая область показывает сетку проектов и все задачи; отдельный dashboard проектов открывается в диалоге.
- Создание задачи доступно через Add Task и карточку Add new task с плюсом. В общем списке новая задача по умолчанию относится к первому проекту в порядке выдачи.
- Описания задач в карточках и Show more отображаются как Markdown. В List описание полное; в Grid/Kanban используется ограниченное по высоте превью. Содержимое редактора остаётся Markdown-текстом.
- Изменение проекта переносит задачу с сохранением ID; дубликат в прежнем проекте не остаётся.
- Inbox и последний проект защищены от удаления. Удаление другого проекта после подтверждения удаляет его задачи.
- Поиск учитывает название задачи, текст описания и название проекта. Фильтры и вид сохраняются отдельно для каждого проекта и общей области.

В Show more поле Due оформлено в стиле остальных полей; время создания в интерфейсе скрыто, но сохраняется в данных.

## Канбан

На десктопе колонки размещаются сеткой в два столбца, ниже 760 px — в один. Стандартный порядок статусов: Overdue, In process, Pending, Completed. Непустые колонки отображаются сначала, пустые — в конце, с сохранением порядка внутри этих групп. При входе в Kanban пустые колонки свернуты. Заголовок каждой колонки работает как аккордеон; при повторном входе состояние раскрытия сбрасывается.

Каждая задача находится в одной колонке. Overdue — вычисленная группа, а не сохраняемый статус. Перетаскивание между обычными колонками меняет статус. Просроченная задача остаётся в Overdue при смене Pending/In process, пока срок не изменён; Completed выводит её из Overdue. Перетаскивание в Overdue не меняет срок. На мобильных устройствах статус удобно менять select на карточке.

## Размеры и адаптивность

Header остаётся над рабочей областью. Sidebar и main ограничены доступной высотой окна и прокручиваются независимо: переполнение одной области не прокручивает другую или всю страницу. На мобильных экранах drawer проектов имеет собственную прокрутку, а main сохраняет своё положение.

Main занимает всю доступную ширину справа от sidebar: скроллбар находится у его правого края, а контент сохраняет ограниченную ширину и центрируется внутренними отступами.

Все области используют тонкие скроллбары в цветах интерфейса: sidebar, main, диалоги, редактор и Markdown-блоки. Применены стандартные CSS-свойства и запасное оформление WebKit; точная толщина стандартного скроллбара зависит от браузера и настроек системы.

| Ширина     | Поведение                                                                                        |
| ---------- | ------------------------------------------------------------------------------------------------ |
| 360–398 px | Drawer проектов; три кнопки над main вертикально; Grid скрыт и временно представлен как List     |
| 399–759 px | Drawer проектов; кнопки Projects/Add Project/Add Task горизонтально; Grid с карточками от 294 px |
| От 760 px  | Sidebar постоянно слева; кнопки добавления в header; desktop-раскладка                           |

Мобильный блок действий отделён от контента нижней линией. Sidebar внутри drawer остаётся вертикальным. Дата и время всегда справа в header. Сетка автоматически выбирает число колонок, минимальная ширина карточки — 294 px. Расширение экрана восстанавливает сохранённый Grid.

Кнопки центрируют текст и иконки по обеим осям. Select использует собственную стрелку и равные крайние отступы. Часы показывают локальную дату и время браузера, формат 12 часов с AM/PM, обновляются каждую секунду.
